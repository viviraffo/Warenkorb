# 🛒 Warenkorb – Tailwind CSS Projekt

Ein einfaches und modernes Warenkorb-Benutzeroberflächen-Projekt, erstellt mit **HTML5** und **Tailwind CSS**.

## 🔗 Live-Vorschau

👉 **[Warenkorb Live-Demo ansehen](https://viviraffo.github.io/Warenkorb/Warenkorb.html)**

---

## 🛠️ Verwendete Technologien

- **HTML5**: Struktur der Website
- **Tailwind CSS** (via CDN): Styling und responsive Design
- **GitHub Pages**: Hosting der Live-Vorschau

---

## 📦 Features

- 📱 **Responsive Layout**: Passt sich automatisch an Desktop- und Mobilbildschirme an (Flexbox Layout).
- 🛍️ **Produktübersicht**: Darstellung von Artikeln inklusive Lagerbestand und Preis in Schweizer Franken (CHF).
- 📑 **Bestellübersicht**: Übersichtlicher Checkout-Bereich mit Gesamtsumme und Checkout-Button.
- 🎨 **Modernes UI**: Abgerundete Ecken, Hover-Effekte und klare Farbkontraste.
